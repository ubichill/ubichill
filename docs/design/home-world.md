# ホームワールドとランチパッド（ロビーの撤廃）

ロビー（`/` の一覧画面）をなくし、ログインしたら自分のホームワールドの部屋（毎回新しく作る）へそのまま入る。
ワールドを探す・フレンドのところへ行く・部屋を移る・設定などは、部屋の中のランチパッド（HUD）でページを移らずに行う。

## データ

`user_settings` に 2 列（移行 `0028_home_world`）。行が無い人は既定として扱う。

| 列 | 型 | 既定 | 意味 |
|---|---|---|---|
| `home_world_ref` | text | NULL | ホームのワールドの正規 URL。NULL は公式の既定ワールド（`DEFAULT_HOME_WORLD_REF = 'default'`） |
| `home_access_type` | `instance_access_type` | `invite_only` | ホームの部屋の公開範囲 |

- 既定を招待のみにするのは、ログインのたびに公開一覧へ部屋を出さないため。
- 保存する前にワールドを解決し、正規 URL にそろえる（共有 URL `@handle/name` などを貼られても、今いる部屋がホームかを URL で比べられるように）。開けない URL は 400。
- ホームの部屋を見分ける列（`instances.kind`）は足さない。「自分がリーダー・ホームのワールド・ホームの公開範囲」の部屋をホームとみなす（ランチパッドの印と「ホーム」を押せるか。`isHomeInstance`）。

## API（`/api/v1/users`）

| | |
|---|---|
| `GET /me/home` | 設定とホームのワールド（開けなければ `world: null`） |
| `PUT /me/home` | `{worldRef?: string \| null, accessType?}`。省略した項目は変えない。null で既定に戻す |
| `POST /me/home/instance` | ホームの部屋を新しく作る。`?fallback=default` で設定を無視して既定のワールド |

`POST /me/home/instance`（`services/instances/homeInstance.ts`）:

1. 設定のワールドを解決する。開けなければ既定のワールドにして `fallback: 'unresolvable'` を付ける。既定も開けなければ 502。
2. 呼ぶたびに新しい部屋を作る（自分がリーダー・設定の公開範囲）。使い回さない。
3. 通常のインスタンス作成の上限（IP ごと 10 件/時）には数えず、別に 1 人 10 回/分。

ホームは一人で入る場所なので、前のホームの部屋に誰かいても入らない。前の部屋は空になれば `INSTANCE_EMPTY_TIMEOUT_MS`（既定 5 秒）で片付くので溜まらない。
タブを 2 つ同時に開くと部屋が 2 つできるが、1 アカウント 1 接続なので先のタブは切られ、その部屋も空になって片付く。

## 画面の流れ

```
/auth  → ログイン → from（既定 /）
/      → HomePage: POST /me/home/instance → /instance/:id（replace・state: { fromHome: true }）
/instance/:id が失敗 → / へ replace（入れなかった部屋は履歴に残さない）
```

- `HomePage` は待つ間、インスタンスのロード画面と同じ見た目を出す（遷移の継ぎ目を見せない）。
- 入れなかったあと（`afterInstanceFailure`）:
  - ホームで作った部屋が無い（閉じた部屋にほかのページから戻ってきた。取得が `InstanceNotFoundError`）: 待たずに `/` へ戻り、新しいホームを作って入る。
  - ホームで作った部屋に入れない: 5 秒後に既定のワールドで 1 度だけ作り直す（`state: { useDefault: true }`）。それも駄目なら止まり、「もう一度試す・ログアウト」を出す（`state: { homeFailed: true }`）。
  - 同じアカウントが別のタブ・端末で入ってこの接続が切られたとき（`session:replaced`）は、自動ではどこにも移らず「このタブで入り直す」だけを出す。ホームへ戻すと、新しい部屋を作っては互いを切り合う。
  - 共有 URL・ほかの人の部屋での失敗は、理由を 5 秒見せてからホームへ戻ってそのまま入る。入れなかった部屋の URL を `state: { retryPath }` で渡し、ホームに入れたら「元の部屋をもう一度試す」付きのトーストを出す（閉じるまで残り、ホームを出たら消える）。ホームも用意できずに止まったときは、止まった画面に同じボタンを出す。自分のホームの部屋で失敗したときは出さない。
  - 歯止め: 自動で用意したホームに続けて入れなかった数をタブごとに数える（`sessionStorage` の `ubichill:home-failures`）。数えるのは、ホームを作れなかったとき・ホームから入った部屋に入れなかったとき。どの部屋でも入れたら 0 に戻すので、入れている限り何度ホームへ戻っても止まらない。3 回続いたら止まり、「もう一度試す・ログアウト」を出す。3 は、正常に続けて起こりうる「閉じたホーム → ホームのワールドで作り直し → 既定のワールドで作り直し」を止めない最小の数（3 回目は `homeFailed` で止まる）。時刻では数えないので、間隔の空いた失敗の繰り返しも止まる。
- 既定のワールドに切り替えたときは、入った部屋でトーストで 1 回だけ知らせる（読み込み直しでは出さない）。
- 共有 URL（`/@handle/name`・`/world/...`・`/instance/:id`）はホームを通らない。

## ランチパッド（`components/hud/HudOverlay.tsx`）

部屋の中の右上（スマホは右下）のボタンか Esc で開く。タブは 2 列に分け、その上に画面（招待・ほかの人のプロフィール）を重ねて進む
（戻ると 1 枚ずつ外れる。タブを押すと重ねた画面は忘れる。`hudView.ts`）。狭い画面では左のタブをパネルの上に横に並べる。
ワールド・ソーシャル・設定は、中でさらに左に縦に並べて切り替える（`tabs/SplitTab.tsx`。狭い画面では上に横に並べる）。どの欄を開いていたかは、人を開いて戻っても保つ。

| 下（その場と通知） | 中身 |
|---|---|
| ランチパッド | 現在地（ワールド・公開範囲・人数・ホームの印と「ホーム」「招待」）、オンラインのフレンド、ワールド |
| 現在地 | 今の部屋（入り直し・新しいインスタンス・編集・参加者） |
| 音声 | ワールドのメディア全体の音量・ミュート |
| 通知 | 通知（未読の数を添える） |

| 左（探すもの・人・自分） | 中身 |
|---|---|
| プロフィール（アカウントのアイコンと名前。画像が無ければ頭文字） | 自分のプロフィール。「編集」でその場で編集する |
| ワールド | ローカル・グローバル・お気に入り・自分のワールド（署名・削除などの管理） |
| ソーシャル | ユーザーを検索（一番上・色を変える）・フレンドの現在地（開いたとき）・すべてのフレンド |
| 設定 | ホーム・プライバシー（オンライン状態・お気に入りの公開範囲）・フェディバース（アカウント・フォローの受け方・承認待ち・フォロワー）・公開・アカウント・mod の権限 |

- プロフィールの設定は置かない（プロフィールはプロフィールの画面でその場で編集する）。だれに何を見せるかは「プライバシー」にまとめる。
- フレンドの見出しからソーシャルへ、顔の列の検索から「ユーザーを検索」へ、ワールドの見出しから「ワールド」のタブへ移る。ワールドの見出しの ＋ でワールドを作る。
- **フレンドの現在地**: 部屋ごとに畳めるまとまりにし、見出し（ワールド名・公開範囲・フレンドの数）の下に、部屋のカード（サムネイル・人数・「入る」か「リクエスト」）と
  そこにいるフレンドのカード（顔・名前・ひとこと）を並べる。自分の部屋（フレンドがいるとき）が一番上、見えない部屋のフレンドは最後にまとめる。
- **すべてのフレンド**: オンライン（名前順・いる場所を添える）→ 確認できない（最後に確かめた様子）→ オフライン（ひとこと）→ 申請中。
- **ホーム**: ホームの部屋（新しく作る）へ移る。今いる部屋がホームなら押せない。ほかの人がいるときだけ確認する。
- **招待**: フレンドを選んで今の部屋に招待する（`docs/design/social.md` の「招待とリクエストインバイト」）。
  招待のみでない部屋は、入れる人に渡すリンク（`/instance/:id`）もコピーできる。招待のみの部屋は URL だけでは入れない。
- 人（フレンド・検索結果・通知）を押すと、ページを移らずにランチパッドの中でプロフィールを開く（部屋から抜けない）。フレンドの解除もそこ。
- 見た目: ランチパッド自体がパネルなので、中の画面は枠で囲まない（まとまりの間は細い線）。ホバーでは動かさず、色だけ変える。

### Esc

- 部屋の中で Esc を押すとランチパッドを開け閉めする（`launchpadKey.ts`）。
- 日本語の変換中（変換の取り消し）・入力欄で打っている間は反応しない。ランチパッドの入力欄で打っているときは、まず入力欄から抜ける。
- 確認・ワールドの詳細などのダイアログが出ている間は、一番手前のダイアログだけが閉じる（`components/ui/dialogLayer.ts`）。
- 乗り物に乗っている間は開かない。mod が Esc で降ろす（弾幕の自機など）ので、降りてからもう一度 Esc で開く。
- mod にも Esc は届く。乗り物以外で Esc を使う mod とは重なる（mod 向けの説明は `docs/API.md`）。

### ソーシャル（`components/hud/tabs/SocialTab.tsx`）

VRChat の「フレンドの現在地」のように、フレンドを部屋ごとにまとめる（`/social/locations` をそのまま使う。サーバーは変えていない）。

1. 自分がいる部屋（公開範囲に関係なく一番上。「ここにいます」の印、入る操作は出さない。同じ部屋のフレンドはここに並べ、ほかの一覧に重ねない）
2. ユーザー検索
3. オンライン: 部屋ごと（フレンドの多い順・同じなら人の多い順）。サムネイル・ワールド名・公開範囲・人数・「入る」とフレンド。見えない部屋にいるフレンドは「プライベート」として名前だけ
4. オフライン
5. 申請中（自分が送った申請。届いた申請は通知）

並べ方は `components/social/friendPresence.ts`（ランチパッドのフレンドの列と共有）。15 秒ごとに読み直し、タブが隠れている間は止める。読み込みはランチパッド・ソーシャル・プロフィールで 1 つを共有し（`sharedPoll.ts`）、画面を移っても 5 秒より新しい答えはそのまま使う。サーバーはユーザーの情報を 1 回でまとめて引く。

ホームの既定は招待のみなので、ログインしたばかりのフレンドはほとんど「プライベート」に出る。フレンドに見つけてもらうには、ホームの公開範囲を「フレンドのみ」などにするか、公開の部屋へ移る。

## 音声

`@ubichill/react` の `mediaOutput`（host 全体で 1 つ）。`<video>` の音量 = mod が `Ubi.media.setVolume()` で決めた音量 × 全体の音量、ミュートは全体で。
mod から見える `state.volume` は mod が決めた値のまま（全体の音量で mod の UI が動かないように）。値は端末の localStorage（`ubichill:media-output`）。

## 未対応・判断待ち

- ロビーをなくしたので、ランチパッドを開かない限り公開インスタンスの一覧が目に入らない。既定のホーム（公式の `default`）にほかの場所への入口を置くかは別に決める。
- 署名の無いワールドをホームにすると、入るたびに入室の確認が出る（確認を飛ばす経路は作らない）。
- ログインしていない人の `/` は今までどおり `/auth` へ。ランディングページは作っていない。
